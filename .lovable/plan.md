# CareerPilot AI

## Goal
Build the requested CareerPilot AI command centre as the app’s first screen, with a cohesive responsive shell and working page-level interactions.

## Plan
1. Replace the blank home page with the command dashboard, navigation shell, command palette, theme control, notifications, and emergency-stop guardrail.
2. Add dedicated pages for Mission Control, Source Explorer, Job Discovery, Applications, Manual Action Centre, Resume Studio, Cover Letters, Communications, Interviews, Analytics, Career Insights, Agent Activity, Integrations, Security, Usage, and Settings.
3. Add typed, clearly labeled sample records and meaningful local interactions for search, filters, views, URL validation, document review, and safe workflow controls. Do not claim server execution, application submission, email delivery, or live agent status without verified backend responses.
4. Apply the requested dark/light design system, responsive layouts, accessibility and reduced-motion support; add concise setup and integration-status documentation.
5. Run the relevant app tests and inspect the live preview at desktop and mobile sizes.

## Technical details
- Keep the project’s required TanStack Start stack and file-based routes; do not replace it with Next.js.
- The repository has no FastAPI URL, OpenAPI schema, or backend client. Keep backend-dependent operations unavailable and labeled until the referenced contract is supplied; then integrate only documented endpoints.
- Do not add autonomous workers, credential handling, or submission automation in the frontend.
